# assets/

The art the boot panel is baked from (see `tools/genassets.py`):

| | |
|---|---|
| `logo.png` | 128×128 RGBA, opaque, `#BFBFBF` plate, placed dead-center |
| `spinner/00..11.png` | 12 grayscale 30×30 frames, plate at `#BFBFBF`, drawn as-is |

After editing anything here: `make assets && make`.
